# Ma Page Perso 📸💻

Bienvenue sur le dépôt de ma page personnelle. Ce projet a été réalisé durant l'été 2026 en préparation de ma formation CDA (Concepteur Développeur d'Applications) avec le GRETA.

Il s'agit d'un site web statique qui me présente, détaille mon parcours professionnel dans l'informatique, met en avant ma passion pour la photographie (urbex, architecture, paysages) et fixe mes objectifs futurs.

## 📁 Structure du projet

Le projet est structuré de manière simple et légère :
* `index.html` : La structure HTML de la page web.
* `style.css` : Les feuilles de style pour la mise en forme et l'intégration de la police *Inter*.
* `images/` : Dossier contenant les ressources visuelles (notamment ma photo de profil).
* `notes.txt` : Mes notes de travail et de suivi personnelles.

## 🚀 Comment lancer et voir le projet localement

Comme il s'agit d'un site web purement statique (HTML/CSS), il n'y a besoin d'aucun serveur complexe ni d'aucune installation pour le lancer.

### Méthode 1 : Double-clic (Le plus simple)
1. Téléchargez ou clonez ce dépôt sur votre machine.
2. Naviguez jusqu'au dossier racine du projet.
3. Double-cliquez sur le fichier `index.html`. Il s'ouvrira instantanément dans votre navigateur web par défaut.

### Méthode 2 : Via une extension d'éditeur (Recommandé pour le développement)
Si vous utilisez un éditeur de code comme **Visual Studio Code** :
1. Ouvrez le dossier du projet dans votre éditeur.
2. Installez l'extension **Live Server**.
3. Faites un clic droit sur `index.html` et sélectionnez **"Open with Live Server"**. 
4. Votre page s'ouvrira et se rechargera automatiquement à chaque modification du code.

## 🛠️ Technologies utilisées

* **HTML5** : Structuration sémantique du contenu (headers, sections, listes).
* **CSS3** : Design et mise en page responsive.
* **Google Fonts** : Intégration de la police de caractères *Inter*.
